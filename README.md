# MATTERS OF WORLD

A small, responsive surprise page for profile visitors. Click the button to reveal the message and load the Rickroll video. The page requests autoplay after the click; if the browser blocks playback, the embedded player and YouTube fallback link remain available.

## Publish with GitHub Pages

1. Create a public repository named `MATTERS-OF-WORLD` under `RaunakEduc`.
2. Add `index.html` at the repository root.
3. In **Settings → Pages**, publish from the `main` branch and the `/ (root)` folder.
4. The page will be available at `https://raunakEduc.github.io/MATTERS-OF-WORLD/` (GitHub URLs are case-insensitive).
5. Add that URL to the profile README.

The video is embedded from YouTube's privacy-enhanced domain. Autoplay with sound is subject to each visitor's browser settings.
