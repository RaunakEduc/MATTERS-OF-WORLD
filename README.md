# MATTERS OF WORLD

A small, responsive surprise page for profile visitors. Click the button to reveal the message and play the locally hosted `educational stuff.mp4` video. The page requests autoplay after the click; if the browser blocks playback, visitors can start it from the video controls.

## Publish with GitHub Pages

1. Create a public repository named `MATTERS-OF-WORLD` under `RaunakEduc`.
2. Add `index.html` and `educational stuff.mp4` at the repository root.
3. In **Settings → Pages**, publish from the `main` branch and the `/ (root)` folder.
4. The page will be available at `https://raunakEduc.github.io/MATTERS-OF-WORLD/` (GitHub URLs are case-insensitive).
5. Add that URL to the profile README.

Autoplay with sound is subject to each visitor's browser settings.
